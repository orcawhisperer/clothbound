3.2.1   Scaled Dot-Product Attention

The input consists of queries and keys of dimension dk, and values of dimension dv. We compute the dot products of the query with all keys, divide each by √dk, and apply a softmax function to obtain the weights on the values.

Attention(Q, K, V) = softmax ( QKT√dk ) V
(1)

For large values of dk, the dot products grow large in magnitude, pushing the softmax function into regions where it has extremely small gradients. To counteract this effect, we scale the dot products by 1/√dk.

Why divide QKT by √dk, and how does it compare to Bahdanau’s additive attention?
Assuming unit-variance entries in q and k, their dot product grows linearly in variance with head dimension:
Var(q · k) = dk ⇒ Var( q · k√dk ) = 1
Scaling keeps logits near unit variance so softmax avoids saturated gradients. Bahdanau et al. (2015) avoid blowup with a feed-forward layer at higher matmul cost.

In practice, we compute the attention function on a set of queries simultaneously, packed together into a matrix Q. The keys and values are also packed together into matrices K and V:

Attention(Q, K, V) = softmax ( QKT√dk ) V
(1)

While for small values of dk the two mechanisms perform similarly, additive attention outperforms dot product attention without scaling for larger values of dk.

Step-by-step equation breakdown
1. Pairwise scores (QKT): Compares every query vector against every key in one matrix multiply.
2. Variance stabilization (÷ √dk): Prevents large logits from saturating softmax gradients.
3. Value retrieval (× V): Softmax weights blend value vectors into each token’s contextual representation.

06 Install & Quickstart

Up and reading in under a minute.

Native x86_64 and aarch64 Arch package for Omarchy and Linux desktops. Every CLI command works headless with --json.

Step 01 · Arch / Omarchy

Install v0.4.0

Installs the verified release package on x86_64, or builds the same release from source on aarch64 (read the script). Prefer building it yourself? git clone the repo and run ./bin/install.

$curl -fsSL https://clothbound.app/install | bash
Step 02 · AI Agents

Start the local MCP server

Runs read-only JSON-RPC 2.0 over stdio for Antigravity, Claude Code, Cursor, and Codex. Diagnostics go cleanly to stderr.

$clothbound mcp
Step 03 · Terminal CLI

Query your library headless

Instant local SQLite FTS5 search across every EPUB and PDF — no display server required. Also try clothbound list and clothbound notes.

$clothbound search "attention" --json
