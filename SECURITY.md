# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.4.x` | Yes |
| `< 0.4.0` | No |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities (such as SSRF bypasses in URL/OPDS fetching, `book://` WebEngine scheme isolation, keyring credential handling, or local MCP server issues).

Instead, email **orcawhisperer@proton.me** with:

- A description of the vulnerability and its impact
- Reproduction steps or a minimal proof of concept
- Affected Clothbound version and environment

You'll receive an acknowledgement promptly, and we'll coordinate a fix and disclosure once patched.
